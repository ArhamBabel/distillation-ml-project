## 1. Project Overview

This project develops a machine-learning-based surrogate model and optimization framework for
binary distillation columns. Rather than running computationally expensive rigorous simulations
for every design iteration, two Random Forest models are trained on synthetically generated data
(derived from first-principles shortcut equations) to predict:

- **Distillate purity** (`x_D`) — the mole fraction of the light component in the overhead product
- **Reboiler duty** (`Q_reb`, kJ/h) — the energy consumed at the reboiler

An interactive **Streamlit dashboard** then lets engineers enter operating conditions and immediately
receive predictions or run optimization sweeps, without calling the simulator at all.

---

## 2. Problem Statement and Motivation

Distillation is the most energy-intensive separation process in the chemical industry, accounting
for roughly 40 % of a plant's total energy consumption. Selecting the right reflux ratio, number
of trays, and feed composition for a given purity target requires either time-consuming rigorous
simulations or expert intuition.

**Gap:** Most optimisation tools either require expensive licensed simulators (Aspen, PRO/II) or
are too slow for real-time engineering decisions.

**Proposed solution:** Train lightweight ML surrogate models on FUG-equation-generated data, then
use them inside a fast optimisation loop to find energy-minimal operating points in seconds.

## 4. Chemical Engineering Methodology

### 4.1 FUG Shortcut Method

Synthetic data were generated using the classic Fenske–Underwood–Gilliland (FUG) shortcut
method, which provides analytically tractable approximations for binary distillation:

**Fenske equation** — minimum number of stages at total reflux:

```
N_min = log[(x_D / (1 - x_D)) * ((1 - x_B) / x_B)] / log(alpha)
```

**Underwood equation** — minimum reflux ratio:

For a binary mixture with saturated liquid feed ($q = 1$), the feed line is vertical at $x = z_F$.
The vapor composition at the feed-stage pinch point is determined directly from vapor–liquid equilibrium:

```
y_q = (alpha * z_F) / (1 + (alpha - 1) * z_F)
```

The minimum reflux ratio is then calculated from the rectifying section operating line intersecting the pinch point:

```
R_min = (x_D - y_q) / (y_q - z_F)
```

*(Note: The implementation uses this direct binary pinch formulation under the saturated liquid feed assumption rather than solving for the root $\theta$ of the general multicomponent Underwood equation).*

**Gilliland / Molokanov correlation** — relates actual N and R to their minima:

```
X = (R - R_min) / (R + 1)
Y = 1 - exp[(1 + 54.4*X) / (11 + 117.2*X) * (X - 1) / X^0.5]
N = (N_min + Y) / (1 - Y)
```

The dataset was generated by combining sampling with first-principles calculations:
- **Five LHS-sampled variables:** feed composition $z_F$, target distillate purity $x_D$, bottoms composition $x_B$, reflux multiplier $R_{factor}$, and feed flow rate $F$ were sampled using Latin Hypercube Sampling.
- **Separately selected system parameters:** chemical system identifier `system_id` was selected discretely from $\{1, 2, 3, 4, 5\}$, with relative volatility $\alpha$ and latent heat of vaporization $\lambda$ sampled uniformly within the selected system's characteristic bounds.
- **Derived variables:** reflux ratio $R$ ($= R_{factor} \cdot R_{min}$) and theoretical stage count $N$ were calculated directly from the FUG shortcut equations, and reboiler duty $Q_{reb}$ was calculated from the column energy balance. (Note: $R$, $N$, and $Q_{reb}$ are calculated outputs during data generation, not directly sampled independent variables).

### 4.2 Thermodynamic Proxies

The original project proposal listed temperature as a thermodynamic parameter. In this
implementation, **α (relative volatility)** and **λ (latent heat of vaporization)** are used as
the thermodynamic descriptors instead, since the FUG shortcut method is formulated in terms of
α rather than temperature. Each chemical system is characterised by a fixed (α, λ) range that
implicitly encodes the mixture's volatility and energy content.

### 4.3 Five Chemical Systems

| System ID | α range | λ range (kJ/kmol) | Separation character |
|-----------|---------|-------------------|----------------------|
| 1 | 1.5 – 2.0 | 32,000 – 35,000 | Hard (low volatility difference) |
| 2 | 2.0 – 2.5 | 29,000 – 32,000 | Moderately hard |

| `R` | Input | Reflux ratio (derived via FUG in data generation; input feature in ML) | ~0.5 – 17.9 |
| `N` | Input | Number of theoretical trays (derived via FUG in data generation; input feature in ML) | ~6.1 – 43.7 |
| `system_id` | Input | Chemical system identifier | 1 – 5 |

| `lam` | Input | Latent heat of vaporization (kJ/kmol) | 25,000 – 35,000 |

> **Note on variable roles:** During synthetic dataset generation, target purity $x_D$ is sampled while reflux ratio $R$ and tray count $N$ are derived outputs of the FUG equations. In contrast, for machine learning surrogate modeling, $R$ and $N$ serve as operational input features to predict $x_D$ and $Q_{reb}$.

### 5.2 Data Generation

The dataset was generated by `src/generate_dataset.py` using true Latin Hypercube Sampling via SciPy (`scipy.stats.qmc.LatinHypercube(d=5)`) applied across five sampled operational dimensions:
- `z_F` ∈ [0.2, 0.8]
- `x_D` ∈ [0.90, 0.995]
- `x_B` ∈ [0.01, 0.05]
- `R_factor` ∈ [1.1, 2.5]
- `F` ∈ [100, 500] kmol/h

In addition, each sample was assigned a discrete chemical system (`system_id` chosen uniformly from {1, 2, 3, 4, 5}), with thermodynamic proxies `alpha` and `lam` sampled uniformly within the chosen system's characteristic bounds.

The FUG shortcut equations in `src/distillation_physics.py` then calculated the dependent physical parameters:
1. Underwood minimum reflux `R_min` and actual reflux `R = R_factor · R_min`.
2. Fenske minimum stages `N_min` and actual theoretical stages `N` via the Molokanov form of the Gilliland correlation.
3. Reboiler duty `Q_reb = (R + 1) · D · lam` from the material and energy balances.

Rows where $R < 0.5$ or where the Molokanov correlation yielded unphysical values ($X \notin (0, 1)$) were rejected. The final 5,000 rows represent physically consistent, thermodynamically feasible operating points.

### 7.3 Final Models — Random Forest

Random Forest regressors were chosen for their ability to capture non-linear interactions between
operating variables without explicit feature engineering.

**x_D model feature order:** `[R, N, z_F, alpha, F, x_B]`

**Q_reb model feature order:** `[R, N, z_F, alpha, F, lam, x_D, x_B]`

(The predicted `x_D` from the first model is fed as an input feature to the second model.)

**Hyperparameter tuning:** 5-fold cross-validated GridSearchCV over `n_estimators`, `max_depth`,
and `min_samples_leaf`. Best parameters: `n_estimators=500`, `max_depth=None`,
`min_samples_leaf=2`. Best cross-validation R²: **0.6914**.

### 7.4 Model Performance

#### Fair Comparison (Identical Features)

The table below presents a fair comparison between the Linear Regression baseline and the tuned Random Forest models. Both models were evaluated on the exact same 80/20 train/test split (`random_state=42`) using **identical feature sets** ($x_D$: 6 features including $x_B$; $\log(Q_{reb})$: 8 features including $\lambda$, $x_D$, and $x_B$). These represent standalone model evaluations where each model receives the same inputs:

| Model | Target | Features | R² (test) | RMSE (test) | MSE (test) |
|-------|--------|----------|-----------|-------------|------------|
| Linear Regression *(Fair)* | x_D | 6 features (identical) | 0.2546 | 0.023600 | 0.000557 |
| **Random Forest *(Production)*** | **x_D** | **6 features (identical)** | **0.7035** | **0.014885** | **0.000222** |
| Linear Regression *(Fair)* | log(Q_reb) | 8 features (identical) | 0.9490 | 0.150323 | 0.022597 |
| **Random Forest *(Production)*** | **log(Q_reb)** | **8 features (identical)** | **0.9686** | **0.117915** | **0.013904** |

*(For historical reference, the initial 5-feature Linear Regression baseline evaluated prior to feature refinement achieved $R^2 = 0.2431$, $\text{RMSE} = 0.023782$, $\text{MSE} = 0.000566$ on $x_D$ and $R^2 = 0.9403$, $\text{RMSE} = 0.162565$, $\text{MSE} = 0.026427$ on $\log(Q_{reb})$).*

The Random Forest models significantly outperform the Linear Regression baselines, particularly for $x_D$ where the non-linear vapour–liquid equilibrium and stage-reflux interactions cannot be captured by linear terms.

#### Standalone vs. Chained Pipeline Evaluation

In the standalone evaluation above, both models predict $\log(Q_{reb})$ given the ground-truth distillate purity $x_D$ from the test set ($R^2 = 0.9686$).

In production inference (within `src/optimizer.py` and the Streamlit dashboard), ground-truth $x_D$ is unavailable, so the predicted purity $\hat{x}_D$ from the first Random Forest model is passed as an input feature into the second model. When evaluated as an end-to-end chained pipeline on the held-out test set:

- **Chained Random Forest pipeline ($\log(Q_{reb})$):**
  - **R²:** **0.9650** (compared with 0.9686 in standalone evaluation)
  - **RMSE:** **0.124523** (compared with 0.117915 in standalone evaluation)
  - **MSE:** **0.015506** (compared with 0.013904 in standalone evaluation)

The slight drop from 0.9686 to 0.9650 reflects the propagation of surrogate prediction uncertainty from $\hat{x}_D$, but the reboiler duty prediction remains highly accurate across the entire operating range.

> **Note:** Q_reb predictions are made in log-space. The model output is exponentiated (`np.exp()`)
> to recover the physical reboiler duty in kJ/h.

**Distillate purity model (`x_D`):**
- Number of trays (`N`): **24.8 %**

- Feed composition (`z_F`): **16.9 %**
- Bottoms composition (`x_B`): **8.0 %**

*Column size $N$, relative volatility $\alpha$, and reflux ratio $R$ collectively account for over 71 % of tree split importance in predicting purity.*

**Reboiler duty model (`log(Q_reb)`):**

## 8. Distillation Physics and Energy Calculations

Implemented in `src/distillation_physics.py`.

### 8.1 Material Balance

Overall: `F = D + B`

Component (light): `F · z_F = D · x_D + B · x_B`

Distillate flow: `D = F · (z_F − x_B) / (x_D − x_B)`

### 8.2 Vapor Flow (Constant Molar Overflow)

Under the CMO assumption with reflux L = R·D:

```
V = L + D = (R + 1) · D
```

### 8.3 Reboiler Duty

```
Q_reb = V · λ   [kJ/h]
```

where λ is the latent heat of vaporization (kJ/kmol) and V is in kmol/h.

This is a simplified energy balance — it does not account for sensible heat, feed thermal
condition effects, or column heat losses (see `docs/assumptions.md` §8 and §11 for details).

## 9. Optimization Methodology

Implemented in `src/optimizer.py`.

### 9.1 Problem Formulation

**Objective:** Minimize predicted reboiler duty Q_reb

**Decision variables:**
- Reflux ratio R ∈ [max(0.5, 1.1·R_min), min(10.0, 2.5·R_min)], dynamically bounded based on Underwood minimum reflux R_min for the specified purity, keeping the search strictly within the training-supported R_factor ∈ [1.1, 2.5] envelope.
- Bottoms composition x_B ∈ [0.01, 0.05]

**Fixed parameters per call:** system_id, z_F, F, N

**Constraints:**
- ML surrogate constraint: predicted x_D ≥ purity_spec
- First-principles physical feasibility: independent FUG validation requirement FUG_N ≤ N_actual

### 9.2 Algorithm — Grid Search with Independent FUG Validation

A grid search over (R, x_B) is executed using `np.linspace` with 50 points per dimension (2,500 candidate points per optimization call). The procedure operates in four stages:

1. **Physical search space restriction:** Underwood minimum reflux `R_min` is computed for the target purity specification and feed conditions. Reflux bounds are set dynamically to `[max(0.5, 1.1*R_min), min(10.0, 2.5*R_min)]`, ensuring candidates lie within the training-data support region and strictly above minimum reflux.
2. **Surrogate purity filtering:** The `x_D` Random Forest predicts distillate purity across the 2,500 grid points. Points failing `predicted x_D >= purity_spec` are discarded.
3. **Surrogate energy evaluation:** For all purity-feasible points, the `Q_reb` Random Forest predicts reboiler duty (in log-space, exponentiated to kJ/h).
4. **Independent FUG physical validation:** ML-feasible candidates are sorted by predicted reboiler duty in ascending order (lowest energy first). Each candidate is evaluated against the independent FUG shortcut equations (`src/distillation_physics.py`). A candidate is accepted only if the theoretical stages required by FUG satisfy:
   ```
   FUG_N <= N_actual
   ```
   The lowest-energy candidate passing this test is returned as the optimal design. If all candidates fail, the optimization returns `feasible: False`. ML surrogate feasibility alone is strictly not sufficient to accept a recommendation.

### 9.3 Tray Trade-off Analysis

`src/run_tradeoff.py` calls the `n_sweep()` function (also in `optimizer.py`) to run the
optimizer at a sequence of N values (N = 8, 10, 12, 14, 15, 16, 17, 18, 20, 25) and plot
Q_reb vs. N. This shows the classic trade-off: more trays require less reflux (lower Q_reb)
but increase capital cost.

The trade-off plot is saved to `docs/qreb_vs_N_tradeoff.png`.

## 14. Limitations and Assumptions

### Physics simplifications

| Assumption | Classification | Detail |
|------------|----------------|--------|
| Constant Molar Overflow (CMO) | Established Principle | Equimolar overflow assumed in rectifying section |
| `V = (R+1)·D` vapor flow | Established Principle | Derived from CMO + material balance |
| `Q_reb = V · λ` energy balance | Established Principle | Simplified; excludes sensible heat and column losses |
| FUG shortcut equations for data generation | Established Principle | Valid for binary, ideal-ish mixtures |
| Saturated liquid feed (q = 1) | Project Assumption | Simplifies Underwood equation |
| λ sampled 25,000–35,000 kJ/kmol | Project Assumption | Representative range for common organics |
| F sampled 100–500 kmol/h | Project Assumption | Moderate industrial scale |

### ML model limitations

- x_D Random Forest R² = 0.7035 — predictions carry meaningful uncertainty; not suitable
  as the sole basis for column commissioning decisions.
- Models were trained on synthetic FUG data, not on real plant data or rigorous-simulation data.
- Extrapolation beyond the training ranges of any input variable is unreliable.
- The optimiser uses a 50×50 grid search — finer grids would improve optimality at higher
  computational cost.

### Thermodynamic deviation from proposal

The original project proposal listed temperature as a thermodynamic input. This implementation
uses **relative volatility (α)** and **latent heat (λ)** as thermodynamic descriptors because
the FUG shortcut method is naturally parameterised by α, not temperature. Each of the five
chemical systems encodes a characteristic (α, λ) range that implicitly represents a class of
mixtures.
